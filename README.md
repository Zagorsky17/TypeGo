# TypeGo

Офлайн-тренажёр слепой печати для русской и английской раскладок. Упражнения подстраиваются под ваши слабые места. Написан на чистых HTML, CSS и JavaScript: без сервера, сборки, npm и внешних библиотек.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` двойным щелчком.

Всё работает прямо с диска (`file://`), интернет не нужен. Прогресс хранится в `localStorage` браузера.

## Возможности

- **Пошаговое обучение с нуля.** Учебный план из 12 этапов: посадка, домашний ряд, остальные буквы, сочетания, слоги, слова, предложения с заглавными, пунктуация, цифры, реальные тексты, скорость и спецсимволы. Новые клавиши открываются небольшими группами, а к следующему уроку можно перейти только после освоения текущего (Mastery Learning).
- **Диагностика.** Если вы уже умеете печатать, короткий тест определит уровень и пропустит лишние уроки.
- **Адаптивные упражнения.** Генератор оценивает каждую клавишу (точность, скорость, стабильность, объём практики, давность) и составляет упражнение: примерно 60% слабых мест, 30% повторения и 10% нового.
- **Интервальное повторение.** Упрощённый алгоритм SM-2 на уровне отдельных клавиш напоминает о тех, что пора повторить.
- **Режимы тренировки:** адаптивная практика, слабые клавиши, точность (остановка на каждой ошибке), скорость, реальные тексты, свободная печать, тесты на 60 и 120 секунд, интервальное повторение, разминка.
- **Ежедневная тренировка** на 5, 10 или 15 минут из нескольких шагов, серия дней подряд и напоминание сделать перерыв.
- **Статистика:** скорость (CPM/WPM), точность, тепловая карта клавиатуры, графики прогресса, проблемные клавиши, пары букв и частые путаницы.
- **Свои тексты.** Можно добавить собственные тексты и печатать их.
- **Несколько учеников** в одном браузере. У каждого свой прогресс, отдельно для русской и английской раскладок.
- **Раскладки:** русская ЙЦУКЕН (ПК и Mac «Русская», определяется автоматически) и английская QWERTY. Если в системе включена другая раскладка, нажатия распознаются по физическим клавишам.
- Интерфейс на русском и английском, светлая и тёмная темы.
- **Резервная копия.** Прогресс можно экспортировать в JSON-файл и восстановить из него. Перед импортом и сбросом автоматически создаётся копия.

Пороговые значения адаптации (точность для прохождения урока, порог «слабой» клавиши и т.д.) можно менять в настройках.

## Структура проекта

```
index.html          точка входа, порядок подключения скриптов
css/styles.css      стили
js/config.js        все настраиваемые пороги и веса
js/util.js          вспомогательные функции
js/i18n.js          строки интерфейса (ru/en)
js/layouts.js       раскладки клавиатуры
js/data/            словари и библиотека текстов
js/storage.js       хранение, миграции, резервные копии, работа в нескольких вкладках
js/texts.js         пользовательские тексты
js/stats.js         подсчёт результатов сессии
js/mastery.js       оценка освоения клавиш и интервальное повторение
js/curriculum.js    учебный план и условия перехода
js/generator.js     генератор упражнений
js/engine.js        обработка нажатий во время сессии
js/keyboard.js      экранная клавиатура
js/charts.js        графики
js/ui.js            экраны и действия
js/app.js           запуск приложения
tools/audit/        проверочные скрипты
docs/AUDIT.md       результаты аудита
```

Скрипты подключаются как обычные `<script>` (ES-модули не работают на `file://`) и регистрируются в глобальном пространстве имён `window.TG`.

## Проверки

Тестового фреймворка нет, проверки — это обычные скрипты для Node.js в `tools/audit/`. Скрипты `verify-*` и `e2e*` запускают headless Chrome.

```sh
# синтаксис
for f in js/*.js js/data/*.js; do node --check "$f"; done

# движок и весь учебный план
node tools/audit/repro-engine.js
node tools/audit/sim.js "$PWD"

# хранение, схема данных, XSS, интерфейс (headless Chrome по file://)
for s in storage schema xss ui misc; do
  node tools/audit/verify-$s.mjs "$(mktemp -d)" "$PWD/index.html"
done
```

Подробнее о проверках — в [docs/AUDIT.md](docs/AUDIT.md).

## Совместимость

Основная целевая платформа — актуальные версии Chrome и Edge на компьютере. Firefox, Safari и мобильные устройства должны работать, но ещё не проверены вручную (см. `docs/AUDIT.md`).
