## Как исправлено (этап 1)
- **Повреждённые данные.** `readRaw` различает состояния missing / ok / corrupt / unavailable. Повреждённые данные копируются в `<ключ>.corrupt.<время>`; если копию сохранить не удалось, запись в этот ключ блокируется. Повреждённый или удалённый индекс восстанавливается по ключам пользователей.
- **Несколько вкладок.** `state.rev` проверяется перед каждой записью, индекс обновляется по схеме «прочитать → изменить → записать». Если другая вкладка изменила данные, а в этой нет несохранённых изменений, свежие данные принимаются молча (`adoptExternal`); иначе — конфликт, запись приостанавливается, показывается баннер с кнопкой «Перезагрузить». Состояние без изменений не записывается, чтобы простое переключение вкладок не вызывало ложных конфликтов.
- **Ошибки записи.** Результат каждой записи учитывается, флаг ошибки больше не маскируется. При переполнении история аварийно сжимается и запись повторяется. Баннер проблемы виден на любом экране. Для своих текстов действуют лимиты `CONFIG.TEXTS`: 20 000 символов на текст, 150 000 на все тексты.
- **Сохранение на мобильных.** После тренировки вызывается `saveNow()` сразу, вместо `beforeunload` используется `pagehide`.
- **Более новая версия приложения.** Такие данные не перезаписываются, а импорт файла новой версии отклоняется.

## Как исправлено (этап 2)
- **Проверка схемы.** `migrate` → `shape` + `sanitize`: все поля из хранилища и из файлов приводятся к допустимым типам и диапазонам, списочные значения сверяются со списком допустимых, некорректные записи отбрасываются. `validate` проверяет только признак приложения — остальное исправляет `sanitize`.
- **Экран восстановления.** Ошибки при отрисовке экранов, в обработчиках действий и при вводе ведут на экран восстановления («на главную» / «скачать данные как есть» / «сбросить профиль»), а не к пустой странице.
- **Импорт и сброс.** Импорт в текущий профиль спрашивает подтверждение со сводкой файла. Перед импортом и сбросом делается резервная копия `typego.v1.u.<id>.bak`; в Настройках есть кнопка «Вернуть данные от …». Если копию сохранить не удалось, импорт отменяется.
- **Файлы.** Файлы больше 10 МБ отклоняются; повторный выбор того же файла работает. При импорте профиля с уже существующим именем требуется подтверждение.

## Как исправлено (этап 3)
- **Экранирование.** Каждое значение из данных, которое попадает в разметку, экранируется: числа — через `U.num()` + `esc()`, строки и атрибуты `data-action` — через `esc()`, `fontSize` сверяется со списком допустимых. Проверка нашла ещё одно место, пропущенное при аудите, — плитку «Серия занятий» в Статистике.
- **Индекс профилей.** Имя и цвет нормализуются при чтении: цвет — только `#rrggbb`, чтобы исключить CSS-инъекцию через `style`.
- **CSP через `<meta>`.** `default-src 'none'`; скрипты — только собственные (`'self' file:`); без встроенных обработчиков, сети, фреймов и воркеров. Источник `file:` добавлен, потому что на `file://` `'self'` в разных браузерах трактуется по-разному. Проверено в Chrome; в Firefox и Safari — ручная проверка из чек-листа.

## Как исправлено (этап 4)
- **Раскладка ОС.** Любая буква показывает раскладку ОС: если она не совпадает с уроком, сессия переходит в режим «по физической клавише» (`codeMode`); буква нужной раскладки возвращает обычный режим. Пока раскладка неизвестна, знак, набранный на физически верной для урока клавише, засчитывается. Все буквы и знаки проверены в обоих направлениях (RU↔EN) и при совпадающих раскладках.
- **Автоповтор.** `e.repeat` игнорируется — в уроках и в свободной печати.
- **Тест на время.** Нажатие после окончания времени не засчитывается: тест завершается, время окончания = начало + лимит.
- **AltGr.** Ctrl+Alt при активном AltGraph пропускается как ввод; обычные сочетания с Ctrl/Alt/Meta по-прежнему игнорируются.

## Как исправлено (этап 5)
- **Уход с тренировки.** Если в тренировке уже есть нажатия, любой уход с экрана (шапка, смена языка или раскладки, профиль, Esc, «Выйти», «Заново») спрашивает подтверждение. Пока открыто окно, нажатия не попадают в урок.
- **Открытие клавиш урока.** Новые клавиши попадают в практику только после завершённой попытки урока, а не при его запуске.
- **Шаг ежедневного плана.** Шаг отмечается по типу (номер — только если тип совпадает): смена длительности или раскладки посреди шага не отмечает чужой шаг.
- **Пороги.** Проверяется согласованность: нижний < средний < высокий ≤ 100, порог слабой клавиши < порога освоенной, требования точности ≤ 99. Недопустимое значение не сохраняется, и показывается объяснение. Несогласованные пороги из файла заменяются значениями по умолчанию.
- **Свободная печать.** Вставка и перетаскивание текста запрещены; Esc при набранном тексте спрашивает подтверждение.
- **L7.** Закрыт на этапе 2: после импорта профиль перерисовывается, только если пользователь всё ещё на экране профилей.

  - проверка схемы (H1);
  - CSP через `<meta>`:
    ```
    default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; connect-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'
    ```
